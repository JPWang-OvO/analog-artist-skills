# 手工绘图回迁与重建

用户要求保存 OA 手工修改、将其纳入源码或重建已有图面时，使用本流程。
回迁将原生绘图保存为可重放的展示配置；重建从该配置恢复目标视图。

## 回迁

1. 确定要保存的 library、cell/view。按修改时间筛选候选视图时统一比较 epoch，
   再读取原生内容确认实际变化。对照上次交付的展示配置与当前 OA，区分新增手工调整和本次要求修改的部分。
2. 保存实例位置与朝向、pin、wire、附属标签、symbol 图形、选择框和 Note。
   保留图层、标签类型与表达式、字体、字号、朝向和曲线参数。器件属性按原生类型保存，
   CDF 显示字符串用于图面显示。
3. 写入项目展示配置，检查其与 OA 内容的对应关系。纯回迁以读取 OA、保存配置和比对
   完成，远端手工视图保持原样。配置格式、存放位置与视图登记方式沿用目标项目约定。

继续编辑时，以回迁后的配置为起点，沿用未受本次要求影响的手工位置、走线和局部样式。
涉及实例、端口或拓扑的 OA 差异需与电路源码核对，按授权范围同步电气定义与展示配置。

## 重建

先核对配置与当前电路的实例、端口集合，按拓扑变化更新配置及映射。
按保存的坐标、朝向、几何和原生属性类型恢复图面。完成后读取实际连接，
检查端序、标签归属和共享端点，渲染目标视图并审阅父级中的显示。

实际修改 schematic 后执行 Check/Save；修改 symbol 后保存并检查接口，
引脚位置变化时检查全部直接父级，按变换后的 pin 坐标整理完整引出路径及附属标签，验证实际连接。
