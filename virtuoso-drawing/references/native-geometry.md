# 原生绘图尺度、几何与 SVG 转换

构造细节、移动 pin、导入 SVG 或检查保存结果时，按目标数据库精度与原生对象核对几何。

## 字体与绘图尺度

以下是一组可复用的绘图起点，数值采用 Virtuoso 原生原理图坐标单位。
用户要求与目标项目已有设置优先；采用这些数值前，核对目标数据库分辨率及父级接口格点。

| 项目 | 建议起点 |
|---|---|
| Symbol 字体、字号 | `stick`、高度 `0.0625`，用于内部说明、位宽、pin 名、cell 名和实例名 |
| 正负号 | 可局部使用高度 `0.1`，按功能图形比例调整 |
| Snap spacing | `0.03125`，用于主要图形坐标和文字锚点的对齐 |
| 电气连接格点 | `0.0625`，用于 symbol pin 中心、实例变换后的 pin 坐标及父级 wire 接合端点 |
| 同侧 pin pitch | 从 `0.125` 开始，按标签、功能分组和局部几何调整 |
| Schematic net label | 高度 `0.0625`、`lowerCenter` 对齐、距线垂直偏移 `0.04375` |

细小图形按辨识度保留适当尺寸；SVG 导入时独立设置原生字体大小。
矩形 pin 的尺寸按下节的整数 DBU 规则确定。

## 坐标精度与格点

区分三种尺度：

| 尺度 | 用途 |
|---|---|
| 数据库坐标步长 | 决定几何坐标的存储精度，等于目标 cellview 每用户单位 DBU 数的倒数 |
| Snap spacing | 控制编辑器交互绘制与移动时的坐标吸附 |
| 电气连接格点 | 项目规定的 pin 连接锚点对齐要求 |

读取目标 cellview 的数据库分辨率，按整数 DBU 构造细节坐标与尺寸。
矩形 pin 的半尺寸取整数 DBU，保存后以原生包围盒中心核对位置，保证中心可精确落在电气格点上。
同时核对实例经过平移、旋转或镜像后的 pin 坐标，以及父级 wire 的接合端点。

例如，在分辨率为 160 DBU/用户单位的 cellview 中，数据库坐标步长为 `0.00625`。
上述 snap spacing 对应 5 DBU，电气连接格点对应 10 DBU；坐标 `0.03125` 可被精确保存，
也落在 snap 格点上，但位于两个电气连接格点之间。
矩形 pin 半尺寸 `0.0125` 对应 2 DBU；`0.015625` 对应 2.5 DBU，边界量化可能使保存后的中心偏离预定格点。
这些换算以示例分辨率为前提，实际尺寸按目标 cellview 计算，并按保存后的原生包围盒验收。

小圆点、反相圆圈、电阻折线、虚线和 pin 图形的尺寸按辨识度确定，曲线参数和标签偏移按用途及原生几何处理。
保存坐标使用与数据库精度相符的简洁十进制，清除浮点尾差；读回保留原生精度，线宽采用原生实际保存的值。

## 图元与接合

局部图元从共同的圆心、轴线和尺寸构造。逻辑门按已有标准单元库中的对应 symbol 取形。

| 图元 | 几何与显示 |
|---|---|
| 连接点与空心圆 | 圆的包围盒宽高相等，圆心与相连引线同轴；实心连接点的圆心落在实际线段上。汇接点实心，反相圆圈和开关触点空心，尺寸按用途区分 |
| 反相器与时钟边沿 | 以信号轴对称绘制等腰三角形或开口楔形，输入引线接底边中点。反相器的尖端、反相圆圈圆心和输出引线同轴，圆圈与尖端相切，输出线从圆周引出 |
| 流向箭头 | 用实心等腰三角形；底边中点和尖端均落在所属引线段上，底边垂直于该线段，尖端指向信号或控制传播方向 |
| 总线斜杠 | 斜杠中点落在所标总线的轴线上，两端跨过总线；位宽标注贴近对应标记 |
| 电阻与参考梯 | 电阻体与两侧引线同轴；等距串联梯连接两端参考节点并关于其中点均匀布置，电阻体位于相邻节点中间，两侧引线等长，抽头从节点中心引出 |

## 布局调整与 SVG 转换

先定位端口与主要路径，再按局部尺寸构造或复用图元。局部门形、圆形和三角形保持等比缩放，
分段坐标映射只用于布局锚点；坐标轴翻转时同步变换箭头方向。

移动 pin 或主要轴线时，以完整连接路径及关联功能组整理引线、节点、箭头、总线标记、标签和框体，
保持共同轴线。图元尺寸变化时同步引线接合点与相邻折点。

分别处理几何尺度、字体、原生动态标签和选择框。按图元用途映射实心、空心图层，
核对目标 display resource 下的实际显示，并用保存后的原生几何和截图检查转换结果。
