# Virtuoso 原理图与 symbol 绘图

通过布局、连线和功能图形，让读者识别电路作用、沿线理解关键路径。
在器件、文字和连线互不遮挡的前提下，收紧功能组与接口，形成紧凑、均衡的图面。

执行 OA 操作需要可用的 Virtuoso 访问工具，先查该工具的 API 文档与示例；
环境中安装了 `virtuoso` skill 时，按其操作说明访问。
从用户要求、目标项目设置与现有原生视图确定字号、格距、颜色、pin pitch 和参考 cell。
绘图配置的存放与重建方式沿用目标项目约定。

## 理解任务与当前 OA

- 确认目标 CIW、library、cell/view 和任务范围，沿用已有明确授权。参考库仅用于读取。
- 读取电路源码的端口、拓扑、模型和参数，以及目标 OA 的原生对象、几何和相关父级。
  修改已有视图前，对照上次交付配置、当前 OA 与本次要求，按[回迁与重建](references/manual-drawings.md)
  保存新增手工修改，以回迁结果继续编辑，保留任务范围外的构图和局部样式。
- 分别维护电气定义与展示配置。网名、端序、连接和参数依据电路源码；位置、朝向、
  分组、线段、标签和图形写入展示配置。PDK 与标准单元使用其原生 master 接口。
- 用户指定的参考和手工调整优先。各种逻辑门均参考已有标准单元库中对应的 symbol，
  按功能、输入数和极性选择门形，读取其实际几何与引线接合。

## 安排构图

先确定功能组与主路径，再共同安排器件、端口、文字和走线空间：

| 电路尺度 | 排布重点 |
|---|---|
| 晶体管级 | 差分支路对称，匹配器件对齐，堆叠顺序明确，信号器件、负载和偏置关系可辨 |
| 阵列与重复级 | 电容按位权、比较器按阈值、延时链按级次排列，突出公共轨与局部控制 |
| 系统与 TB | 主信号从左向右，激励、电源、时钟、控制、偏置和观察点按功能分区 |

- 同时检查接口 pin 与内部信号族，按输入、输出及功能分组，明确 bus 和重复结构的表达。
  电源通常置上、地置下，体端和阱连接短而清楚；激励与电源采用紧凑短行。
- 调整器件和模块的相对位置，使相连端口、引出方向与重复支路对齐。反馈与延时模块靠近其作用路径，
  驱动器靠近受控开关。按图形和文字的实际边界留出引线空间，竖排网名按实际横向占用留间距。
- 相邻器件、主信号、反馈、关键采样和电荷传递路径优先用连续导线表达；长距离辅助分发使用命名网络。
  选择时考虑绕线是否穿越其他功能组，以及标签带来的查找负担。先调整相对位置，再整理仍需绕行的连接。
- 收紧组内间距并统一重复节距，再安排组间距离。保留可读字号与可辨识的引线、箭头长度，
  局部门形、圆圈和边沿标记保持比例。内部成组图元留白均衡，图框贴合内容，标题栏小而清楚。
  使用相对位置和稳定实例名组织局部修改；手工图按保存的原生坐标重放。

## 实现原生视图

### Schematic 连线与辅助图形

- 从原生 terminal 的坐标与朝向确定引脚位置及引出方向，以文字边界作为避让区域。
  采用正交走线，对齐后合并共线段，去掉多余折点和无用途的末端支段，随导线整理附属标签。
  交叉与汇接使用清楚的连接点表达，分开有歧义的四路交点。
- 原生 wire label 绑定实际导线，放在导线一侧并沿线显示；文字位置独立于电气连接。
- 确认有意悬空的端口或 net 后，在短线末端放置同向的 `basic/noConn`。
  同类悬空信号使用紧凑总线名和匹配位宽的 noConn 实例阵列，逐位核对原生连接与导出网表。
- 辅助图框、线和分区使用 `schCreateNoteShape`，标题与注释使用 `schCreateNoteLabel`。
  保留原生 Note 类型及图层，使 **Edit → Select → Filter** 能分别控制 **Note Shape / Note Text**
  的可选状态；颜色和线型遵循项目设置。

### Symbol 功能图与接口

- 用功能形状和简洁内部示意表达采样、比较、放大、存储、延时或量化等作用。
  复合模块展开决定功能的内部架构，辅助逻辑可用短功能框组织，同类器件采用一致的视觉语言。
- 明确每条控制线的对象与作用，接到对应的时钟、使能、选择、复位或开关控制端。
  寄存器的时钟入口、边沿标记与名称放在一起。实际信号、时钟和反馈用连续实线；
  锁存反馈表达交叉耦合关系，控制关联的辅助引导线可用虚线，传播方向不明显的路径添加箭头。
- 差分输入相邻，输入一般在左、输出在右，电源与控制按功能成组。
  从项目 pin pitch 起步，将主体、引脚、内部图、名称和父级引线一起安排。
  按端口数、标签长度和内部图形确定尺寸，长标签侧可加宽或移动图形。
- 内部短线末端的功能标注正对引线，文字对齐方式随引线方向确定；外部 pin 名贴近对应端口，
  底部控制文字可竖排并对齐 pin。Cell 名和实例名使用原生动态标签 `[@cellName]`、`[@instanceName]`，
  保留图层及 `NLPLabel` 类型；功能说明和 pin 名保留各自原生标签语义。
- 主体与内部功能图使用功能图形对象。复杂模块的外框边界与对应 pin bank 对齐；
  独立选择框使用 `instance/drawing`，按所需选择范围同步边界。少引脚器件按功能形状处理。
- 分别管理引脚物理位置、netlisting terminal order 和电气方向。电容板、传输开关等双向节点
  使用 `inputOutput`。出现 shorted-output 警告时，依据拓扑检查驱动关系和端口语义，
  修正相关 schematic/symbol 的方向。复制参考 symbol 时按目标接口更新引脚、方向、图形和端序。

### Bus 与实例阵列

- 连续且语义一致的信号族可合并为 bus terminal；明确位序与标量映射，symbol 中用实线总线表达。
- 相同 master、相同有效参数的重复器件可采用 `X<m:n>` 迭代实例。区分逐位与广播连接，
  保存原实例到阵列成员的映射。独立切换支路需要复杂网名排列时，采用可见支路表达。
- 按任务授权范围修改源接口或网名，同步相关 TB、保存信号、波形名、分析脚本和父级绑定，
  检查正向、反向与广播展开。展示顺序独立于源码声明顺序；移动图形时保留声明顺序及阵列成员映射。

### 字体、格点与几何

- 按项目设置使用字体、字号和 snap spacing；确定新图的基准时参考[字体与绘图尺度](references/native-geometry.md#字体与绘图尺度)。
  Symbol 的 pin 名、内部说明、位宽、
  cell 名和实例名采用一致的基准字号；SVG 导入时独立设置字体大小。
  文字拥挤时调整位置、朝向、措辞和局部间距，使内部说明在父级常用缩放下可读。
- 主要图形端点、折点、边界和文字锚点按 snap spacing 组织；pin 连接锚点及与其接合的 wire
  端点按项目电气连接格点对齐。调整已有图时就近移动，共享端点一起处理。
- 构造细节、移动 pin 或导入 SVG 时，使用[原生几何与转换](references/native-geometry.md)中的
  数据库精度、图元比例与接合规则。沿完整连接路径同步节点、箭头、总线标记、标签和框体。

## 按改动验收

| 改动 | 检查 |
|---|---|
| Schematic 编辑 | 读取相关原生连接与检查标记，执行 Check/Save |
| Symbol 编辑 | 保存后按原生精度读回几何与接口，核对[图元关系](references/native-geometry.md#图元与接合)。对受影响的直接父级执行 Check/Save 后读取实际连接；引脚变化时检查全部直接父级的变换后 pin 与完整引出路径，同步 wire 端点和标签 |
| Bus、阵列或实例重命名 | 比较模型、有效参数、端序和展开后的逐实例连接；工程单位按等价值比较 |
| 图面编辑 | 渲染受影响的完整功能组及引出路径，放大检查局部接合，再在父级常用缩放下检查功能、文字、连接点、位序和空间占用。仅看图面追踪关键输出，确认能辨认输入来源与控制作用，并区分时钟、使能、选择和复位 |
| 数值整理后重放 | 比较整理前后的原生几何、图层、对象类型与接口，确认图面一致 |
| 手工图回迁或重建 | 按[回迁与重建](references/manual-drawings.md)检查保存内容、重放条件与原生连接 |

检查改动涉及的字体、格点、图层和对象类型，运行受影响的针对性检查。
纯绘图和实例重命名以电气读回与视觉检查验收；重新仿真按电气变更及项目政策决定。
完成后汇报修改范围、检查结果和仍待处理的问题。
