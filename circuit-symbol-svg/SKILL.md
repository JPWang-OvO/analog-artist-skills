# 电路功能 SVG symbol

用形状、端口和连续路径表达电路功能，让 symbol 在父级原理图中仍然清楚可读。

## 理解接口与参考

- 用户指定的参考和手工调整优先。绘制前实际渲染并浏览[视觉参考](references/symbol-style-reference.md)
  中的整组例图，观察比例、疏密、文字、端口组织与功能抽象，按目标电路独立安排构图。
  参考中没有同类电路时，仍可借鉴适用的对齐、分组和抽象方式。
- 各种逻辑门均参考已有标准单元库中对应的 symbol，按功能、输入数和极性选择参考，
  学习门形、引线接合及反相圆圈的表达。具体接口依据目标电路确定。
- 从用户提供的接口说明、网表、HDL 或原理图确认端口名称、总线范围、方向、功能和端序。
  显示位置与电气方向分别处理；右侧的无源端口仍可能是双向端口。
- 确定主信号、反馈、采样与参考路径，以及时钟边沿和复位极性。逐项明确控制信号作用于哪个对象，
  通过时钟、使能、选择、复位或开关控制端产生什么作用。接口或功能缺失且影响画法时，向用户确认。
- 确认重复单元的数量、位宽与独立控制关系，再决定折叠方式；图面保留必要的重复数和位宽。

## 安排构图

1. 确定功能组与主路径。简单器件采用可识别的功能形状；复合模块展开决定功能的内部架构，
   用采样开关、电容阵列、参考梯、比较器、寄存器和反馈路径表达信号处理过程，辅助逻辑可用短功能框组织。
   信号通常从左向右，差分支路围绕共同水平轴镜像。
2. 一起安排端口、内部图、模块名与实例名，按输入、输出、电源和控制功能分组。
   电源通常在上、地在下；控制端靠近作用点，从输入侧或底部引入。按标签实际占用预留空间，
   长标签可沿引线旋转，文字方向与引脚方向分别决定。
3. 调整功能组的相对位置，使相连端口、引出方向和重复支路对齐。采样开关、电容与比较器输入保持平直，
   驱动器靠近受控开关，反馈与延时模块靠近其作用路径，再连接局部路径。
4. 收紧组内间距，统一端口列与重复节距，再安排组间空间。保留可读字号和可辨识的引线、箭头长度，
   通过移动功能组、对齐接口和收拢留白获得紧凑布局，局部门形、圆圈和边沿标记保持比例。
   复杂模块使用贴合内容的细矩形主体，引脚落在边界，内部图元留白均衡。

## 连线与标注

- 相邻功能组、主信号、时钟和反馈优先用连续实线连接，以直线和正交折线为主。
  长距离辅助分发可用短支线与同名标签，别名需明确对应实际输入。选择画法时检查路径是否跨越其他功能组，
  以及读者需要跳转查找多少次；先调整相对位置，再处理仍需绕行的连接。
- 控制线接到相应作用点；表示控制作用或关联的辅助引导线可用虚线。寄存器的时钟入口、边沿标记与名称放在一起。
  锁存反馈清楚地交叉耦合，交叉处无连接点；传播方向不明显的路径添加箭头。
- 多位数据、选择、配置与状态信号用实线总线，以线宽、斜杠和必要位宽标明集合。
  抽头斜接入总线，不把不同抽头画成带连接点的短接公共线。
- 内部短线末端的功能标注正对引线，文字对齐方式随引线方向确定；外部 pin 名贴近对应端口。
  连线避让文字、器件主体和其他端口，标注位置与电气连接分别处理。

## SVG 实现

- 直接编写 SVG，或用小脚本复用图元；保留可编辑的线、路径、文字与分组，用 `viewBox` 管理画布。
- 沿用目标图纸的配色。没有指定风格时，可参考绿色图形 `#287740`、深绿连线 `#425d4a`、
  红色端口 `#c53e32` 和小红方块端点，选择白底或透明底。
- 普通文字可从 16 SVG 单位起步，细线约 1.5 至 2，总线约 2.5 至 3，按最终展示尺度调整。
  端口名、功能字和位宽保持接近的字号；关键正负号可局部放大。
- 图面保留端口、必要节点、位宽、重复数、阻值比例、极性与短功能名。详细映射放在 `<desc>` 或 `<metadata>`。
- 主要端点、折点和边界采用一致格点，差分支路用共同坐标推导。
  每个外部端口建议用唯一的 `data-port` 和对应的 `data-side` 标记；XML 转义尖括号，保留接口的总线写法。
- 构造或缩放局部图元时，按[图元几何](references/symbol-geometry.md)处理共同轴线、比例与接合点。
  布局锚点可单独调整，图元边界变化后同步引线端点与相邻折点。
- 先画主体填充，再画内部图和跨边界线，最后放文字与端口，检查填充是否遮住信号线或控制支线。
- 坐标、半径和线宽按所选绘图精度清除计算尾差。转换到 OA 时，
  按目标数据库分辨率处理几何，并以实际保存的值核对坐标与线宽。

## 检查与交付

1. 展开总线核对端口名称、位数、端序及遗漏或重复，检查控制映射与功能极性。
   仅看图面追踪关键输出，确认能辨认其输入来源及控制作用，区分时钟、使能、选择和复位。
2. 用浏览器或 Inkscape 实际渲染 SVG。放大核对[图元几何](references/symbol-geometry.md)，
   检查包含变换的最终坐标及实心、空心显示；批量生成时检查同类图元的一致性。
   在正常尺寸和父级常用缩放下检查路径、标签重叠、裁切、填充遮线及节点区分，
   与参考图并排观察比例、疏密、文字和端口组织是否协调，核对目标电路的功能表达。
3. 交付 SVG 与预览；修改一组图时同步更新已有合集，保留用户未要求修改的源电路和手工视图。

需要读取或实现 Virtuoso 原生 symbol 时，配合 `virtuoso-drawing` skill 与可用的 Virtuoso 访问工具。
按当前任务范围访问 OA；转换时分别处理几何尺度、字体、原生动态标签和选择框，并核对截图与读回属性。
按图元用途保留实心节点、空心圆圈和实心箭头的显示语义。
