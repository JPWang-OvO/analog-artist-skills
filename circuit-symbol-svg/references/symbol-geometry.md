# Symbol 图元几何

构造、缩放或检查局部图元时使用本参考。门形取自已有标准单元库中对应的 symbol；
按共同的中心、轴线和尺寸组织几何，使引线与图元边界正确接合。

| 图元 | 几何与显示 |
|---|---|
| 节点与圆圈 | 用 `<circle>` 的单一半径保持正圆，圆心与相连引线同轴。汇接点圆心落在实际线段上并显示为实心；反相用较大的空心圆，开关触点用小空心圆 |
| 反相器与时钟边沿 | 以信号轴对称绘制等腰三角形或开口楔形，输入接底边中点。反相器的尖端、圆圈圆心与输出线同轴，圆圈与尖端相切，输出从圆周引出 |
| 流向箭头 | 实心等腰三角形的底边中点与尖端均落在所属引线段上，底边垂直于该线段，尖端指向传播方向 |
| MUX | 输入侧长、输出侧短的对称梯形；输出从短边中点引出，选择端接到斜边 |
| 电阻串 | 统一轴线与抽头节距；密集阵列可用分段等效电阻，保留阻值比例、抽头顺序和数量 |
| 总线标记 | 斜杠中点落在总线轴线上，两端跨过总线；位宽标注贴近对应标记 |
| 比较器与增益级 | 三角形及差分极性清楚，电容到输入保持平直，输出极性与电路一致 |

移动布局锚点时保持局部图元的纵横比例；缩放或改变边界后，同步引线端点、相邻折点和标签。
旋转或坐标轴翻转后，核对箭头方向及接合关系。以实际渲染结果检查实心、空心、遮挡与线条接合。
